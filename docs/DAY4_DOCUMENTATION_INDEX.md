## 📊 Quick Statistics Reference

**Top 3 Statistics to Remember:**
1. **397.7% increase** in unemployment during COVID period
2. **April 2020** - All states peaked simultaneously
3. **69.7% recovery** from peak by November 2020

**Top 3 States Most Affected (Absolute):**
1. Uttar Pradesh: +16.36 pp
2. Delhi: +16.33 pp
3. Maharashtra: +14.34 pp

**Top 3 Insights:**
1. Urban areas experienced 118 pp higher impact than rural
2. Labour participation declined by 11.4%
3. Recovery slowing over time (from 3.52 to 2.16 pp/month)

5. Acknowledge data source uncertainty

### When Citing:
1. Include full document title
2. Note analysis date (September 11, 2026)
3. Reference repository if available
